# ROSE AI OS — Phase 1 Frontend

The Phase 1 interactive prototype is served at `/rose-os/`.

## Run

- Install dependencies: `npm install`
- Start: `npm run dev`
- Open `/rose-os/`

## Included

- ChatGPT-inspired monochrome workspace
- Responsive collapsible navigation
- Admin/client preview switcher
- Simulated assistant and agent execution
- Client, agent, CRM lead, project and workflow management
- Integration catalogue with simulated connection toggles
- Knowledge document picker, analytics, usage, billing and settings
- Local browser persistence for demo records

## Prototype boundaries

No Firebase, real AI inference, OAuth, external API calls, real payments or autonomous execution are enabled. All sample data and actions are local demonstrations.
